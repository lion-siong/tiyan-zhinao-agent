# 体研智脑 Agent 演示说明

建议演示时长 6-8 分钟，始终以真实论文和真实状态为准。

## 1. 首页（30 秒）

展示：

- 21 个导航页面；
- 当前论文库；
- 模型/本地检索状态；
- 从文献采集到学习反馈的完整流程。

## 2. 文献检索与 Zotero（60 秒）

1. 输入“青少年体育锻炼与体质健康”。
2. 展示 Semantic Scholar → arXiv → OpenAlex → Crossref → PubMed 来源看板。
3. 展示真实题录、去重和 DOI 状态。
4. 展示 Zotero Local API 同步入口和独立专题领域。

如果网络受限，不展示虚构结果；说明失败源、回退源和建议。

## 3. 论文库与原文证据（60 秒）

- 打开论文库，展示全文/摘要/仅题录状态。
- 打开 PDF 阅读，展示页码级 `EvidenceRef`。
- 说明没有证据的字段显示“证据不足”。

## 4. 学术争议与知识综合（90 秒）

- 展示同一研究问题内的支持/反对/无显著/未判定论文。
- 展开代表论文原文和证据位置。
- 说明争议是规则初筛，不是专家共识。

## 5. 五层知识图谱（60 秒）

- 默认显示领域和核心主题。
- 展开研究方向、变量和论文证据。
- 切换关系网络，展示变量关系状态。
- 说明 133 节点/1,176 关系只来自正式专题领域当前版本。

## 6. AI 学习测评（90 秒）

- 选择 5 个学习模块生成试卷。
- 展示单选、多选、判断、简答、对比和思辨题。
- 提交一道主观题，展示五维评分、证据引用和扣分原因。

不要展示输入 Key、真实账户信息或受版权限制的完整正文。

## 7. 错题与成长报告（45 秒）

- 展示错题和薄弱知识点。
- 展示五维掌握度趋势与推荐论文。
- 回到下一轮补学题。

## 8. 失败与降级（45 秒）

- 使用独立测试实例关闭模型端点。
- 展示 Function Calling 失败、五源回退、规则检索和用户提示。
- 强调系统不伪造模型结果。

## 9. 结束陈述（30 秒）

项目价值不是“让模型写综述”，而是把真实文献、页码证据、跨论文判断、知识图谱和
学习反馈连成可追溯、可复现的科研流程。
