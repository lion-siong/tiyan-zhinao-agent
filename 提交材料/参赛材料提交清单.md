## 二、正式提交前必须补齐

- [ ] 将项目初始化为 Git 仓库或迁移到已有仓库，并上传 GitHub/Gitee。
- [ ] 将仓库设为 Public，或为评审账号配置访问权限。
- [ ] 建立细粒度提交历史。禁止使用一个 `initial commit` 包含全部功能。
- [ ] 每次提交对应一次核心 AI 对话或一个功能模块，提交信息要能看懂改动目的。
- [ ] 导出至少 3 组完整 Prompt 链，每组包含用户 Prompt、AI 建议、代码修改、Bug 现象、修复引导和最终验证。
- [ ] 若 AI 工具不支持导出，保存完整对话截图或录屏，并按时间顺序编号。
- [ ] 录制 5 至 8 分钟 MP4 演示视频，分辨率 1080p。
- [ ] 视频中包含至少 2 分钟 AI 协同过程复现，例如展示 Prompt 驱动模块生成或引导 AI 修复 Bug。
- [ ] 视频中演示真实功能，不使用静态截图冒充系统运行。
- [ ] 提交最终 PDF 技术报告，确认不超过 30 页。
- [ ] 检查仓库中不包含 `.env`、API Key、用户隐私数据、未授权 PDF 或个人答题记录。
- [ ] 在另一台电脑按 README 的 10 分钟复现指南完成一次干净环境验证。
