# 功能说明

## 1. 科研工作台

输入研究问题，规则规划研究类型、检索策略、证据检索和研究设计检查项，输出可下载
JSON 底稿。报告不会被自动标成已完成。

## 2. 智能文献研究

输入研究问题与返回条数。配置模型时使用 Function Calling 选择公开检索工具；未配置
模型时执行真实规则检索。五个公开来源的失败彼此隔离，界面展示各源状态、耗时和
返回数量。

## 3. PDF 入库与论文库

输入 PDF 或公开题录。系统校验文件、提取书目、计算 SHA-256、去重、页级切分，
并写入专题知识库和 SQLite。只有存在正文证据的论文进入全文阅读；仅题录记录不进入
全文结论。

## 4. 原文证据问答

输入问题和召回数量，使用 BM25/Chroma/混合检索。答案展示论文题名、文件和页码。
模型不可用时返回明确标注的原文摘录；无证据时拒绝补写。

## 5. 论文智能阅读

从当前领域证据中提取目的、对象、方法、干预、对照、测量、结果、统计、结论和局限。
缺失字段显示证据不足，不以模板补造。

## 6. 学术观点与分歧

以研究问题为单位聚合论文级结果方向。只有同一问题出现相反或无显著结果时才形成
争议；不同主题或单篇内部差异不被强行拼接。

## 7. 知识综合与知识图谱

知识综合输出共识、分歧、局限、研究空白和创新方向。知识图谱采用五层：

1. 研究领域。
2. 核心主题。
3. 研究方向与变量。
4. 论文证据。
5. 学术综合。

图谱支持搜索、主题/年份/方法/证据筛选、层级树/关系网络、展开、折叠、缩放和
详情面板。

## 8. 学习测评

五模块：基础知识理解、文献深度理解、文献对比分析、学术思辨训练、个性化错题与补学。

注册题型共 9 种：

- 单项选择题；
- 多项选择题；
- 判断题；
- 简答题；
- 论述题；
- 文献对比分析题；
- 深度理解题；
- 学术思辨题；
- 个性化补学题。

五模块自动预置其中 8 种；论述题保留在注册题型和复习调用路径中。主观题使用
五维评分：核心观点、证据引用、多篇比较、学术逻辑、批判性思维。

## 9. 错题和成长报告

答题分数更新五维掌握度和错题标签；系统推荐论文、复习计划和下一轮补学题。
删除论文后，引用失效论文的题目和答题记录会被清理或失效。

## 10. 数据分析

支持 CSV/XLSX 上传，进行缺失值、描述统计和数值直方图分析。不会将用户上传数据
写入论文库。

## 11. 明确未实现或未验证

- OCR 和扫描版 PDF 文字识别。
- 500 页以上真实文档验收。
- 多租户、权限和公网安全部署。
- 完整任务事件流与操作审计后台。
- 正式 GRADE/PRISMA 专家评价。
- Zotero Web API 写入端到端验收。
