## 1. 本次修正

旧版把“正向结果 + 无显著结果”组合为学术争议，并把无显著论文列入反方。
该逻辑不成立：未达统计显著表示当前样本不足以支持差异结论，不能解释为
效应方向相反。

`v5` 当前只把“正向结果 + 明确负向结果”列为待审核争议候选；
未达统计显著单独记录；所有候选仍须由体育科研教师核对结局定义、干预剂量、
对照条件、测量时点和研究可比性。当前 44 篇活动论文重算后，自动候选为 0 条，
因此旧版“1 个共识、3 个争议”不再作为当前结果。
