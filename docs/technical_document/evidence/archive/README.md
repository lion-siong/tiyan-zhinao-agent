# 技术证据历史归档

本目录保存已经被当前技术文档或测试结果替代的历史材料，仅用于审计和追溯：

- `legacy-exports/`：39 篇、41 篇、3,281 条证据等旧统计快照。
- `legacy-tests/`：178 项旧测试输出和旧汇总 JSON。
- `legacy-comparison/`：争议对照实验的旧版报告。
- `legacy-assets/`：已脱离当前文档引用的旧架构图和知识图谱截图。

当前有效材料仍保存在上级 `exports/`、`tests/` 和对应功能截图位置。
`tools/prepare_submission.py` 默认不把本目录复制到比赛源码包。
