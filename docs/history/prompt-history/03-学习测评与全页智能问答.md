# Prompt 链记录三：学习测评与全页智能问答

## 1. 记录说明

- 记录性质：根据当前对话中真实出现的需求整理，不是原始聊天逐字稿。
- 对应功能：六类题型、全中文选项、标准答案、评分细则、错题本、掌握度和每页智能问答。
- 当前状态：代码和自动化测试已存在；真实主观题模型评分需在配置模型后做页面复测。

## 2. 真实用户 Prompt

第一段：

> 在每个功能上都要个智能问答帮忙解答

第二段：

> ai学习测评做完题要给答案按标准评分，并且选择题不要错位和出现网络地址还有选项要全中文不要出现英文

## 3. 人工约束

1. 每个功能页都能打开与当前页面上下文相关的智能问答。
2. 选择题选项必须与题干对应，不能发生顺序或标签错位。
3. 选项不得包含网址、DOI 链接和无关英文残片。
4. 每题必须有标准答案、评分标准、知识点标签、难度和来源证据。
5. 客观题按明确答案评分；主观题按评分细则评分，不能只依据语言是否流畅。
6. 评分后显示用户答案、标准答案和评分依据。
7. 错题进入错题本，并影响薄弱点、推荐论文和下一轮组卷。

## 4. 设计决策

- 选择题在生成阶段统一构建选项与正确答案索引，新增顺序和中文清洗测试。
- 主观题优先调用模型按量规评分；模型不可用时使用本地关键词量规，并明确评分来源。
- 五维能力初始值和动态更新保存在 SQLite。
- 错题、尝试记录和知识点掌握度分别持久化，复习推荐从真实错题和证据中生成。
- 页面智能问答通过页面上下文映射获得当前功能名称、可用数据和边界提示。

## 7. 真实页面测试计划

1. 完成一轮单选题、多选题、判断题、简答题、论述题和文献对比分析题。
2. 提交后截图用户答案、标准答案、得分和评分依据。
3. 制作至少一题错误答案，确认进入错题本并更新正确能力维度。
4. 检查选项与题干对应关系，确认没有 URL、DOI 链接和无关英文残片。
5. 配置真实模型后执行一次主观题评分，记录模型名称、提示词版本、耗时和返回结构。
6. 模型调用失败时重新测试本地量规回退，确认页面不崩溃且明确标注评分来源。
