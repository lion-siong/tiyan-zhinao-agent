# 体研智脑 Agent 演示视频脚本（5 至 8 分钟）

## 录制原则

- 使用真实运行中的 Streamlit 页面，不用静态截图冒充功能。
- 不展示 `.env`、API Key、个人目录、真实用户姓名、学号、手机号或未授权 PDF 内容。
- 外部接口失败时保留真实提示，说明回退路径，不剪辑成虚假成功。
- AI 协同过程使用真实对话和真实代码/测试修改，至少展示 2 分钟。
- 建议最终成片 7 分 30 秒左右，1920×1080，普通话字幕。

## 分镜与口播

### 0:00-0:35 问题与定位

画面：

- 首页全景。
- 依次指向科研工作台、文献阅读、数据分析、学习测评和系统状态。

口播：

> 体育科研初学者常遇到的问题，不是没有工具，而是选题、文献、数据和学习过程彼此割裂。体研智脑 Agent 将这些环节组织成可检查、可追溯的科研工作流。系统不是普通聊天机器人，也不会把模板内容伪装成真实研究成果。

### 0:35-1:15 架构与真实性边界

画面：

- 展示 README 架构图或 `docs/ARCHITECTURE.md`。
- 高亮 Streamlit、ResearchMind 顺序工作流、BM25/Chroma、SQLite、外部公开接口。

口播：

> 当前系统采用轻量化模块化架构。页面层负责交互，工作流层编排六个职责，工具层完成 PDF、检索和引用，SQLite 保存论文与学习记录。ResearchMind 目前是可调试的顺序工作流，不是自主多 Agent 协商，也没有把 LangGraph 写成已实现能力。外部接口失败时，本地证据仍可通过 BM25 检索。

### 1:15-2:15 科研工作台

画面：

- 输入真实主题：“大学生体育锻炼行为与体质健康水平的关系研究”。
- 展示任务规划、检索式草稿、研究设计模板和阶段状态。
- 展示未执行阶段仍为“待完成”。

口播：

> 这里输入的是一个真实研究主题。系统先生成计划和研究设计草稿，再检索本地真实论文证据。可以看到，尚未执行的步骤不会被标成完成，报告阶段也保持待撰写状态，避免用生成文字替代真实科研过程。

### 2:15-3:20 文献导入、证据与框架

画面：

- 在“我的论文库”或“文献框架”展示论文数、证据数。
- 打开一条证据，显示题名、文件名、页码和原文。
- 展示新 PDF 导入后框架数量变化。

口播：

> 新论文通过统一流程完成校验、SHA-256 去重、页级切分和框架更新。每一条证据都保留论文和页码。Chroma 是派生索引，损坏后可以从原始证据重建；版权和隐私文件不会进入 Git 或公开导出包。

### 3:20-4:35 学习测评与评分

画面：

- 选择一组题，现场完成一道客观题和一道主观题。
- 提交后展示用户答案、标准答案、得分、评分依据和知识点。
- 打开错题本和成长报告。

口播：

> 测评覆盖单选、多选、判断、简答、论述和文献对比。选项全部使用中文，并经过顺序、网址和英文残片测试。客观题按明确答案评分，主观题按量规评分，不只依据语言流畅度。错误知识点会进入错题本，并影响下一轮复习推荐。

### 4:35-6:20 AI 协同与真实 Bug 修复

画面：

- 打开一组已归档的真实 Prompt 记录。
- 展示问题现象、用户约束、修改文件、测试命令和结果。
- 可现场修改一个受控测试输入，运行对应测试，再恢复演示状态。

口播：

> 这一部分展示真实 AI 协同过程。需求不是一次性生成全部代码，而是先限定真实数据、外部接口和版权边界，再逐步实现。这里展示的是论文导入和测评选项修复中的实际问题：先复现，再定位，再做最小修改，最后运行测试。AI 给出的方案要经过人工约束和真实验证，未执行的结果不会写成已通过。

录制时必须使用真实聊天导出或真实当前对话画面，不补拍不存在的 AI 回答。

### 6:20-7:10 测试、回退与安全

画面：

- 终端运行 `pytest`、安全审计或展示真实通过输出。
- 展示无 Key 时的模拟/规则提示。
- 展示 Chroma 不可用时的 BM25 回退或系统状态说明。
- 展示 `.gitignore` 中 `.env`、数据库、PDF 和日志规则。

口播：

> 项目通过自动化测试覆盖论文导入、检索、学习闭环、页面加载和安全审计。真实密钥只从本机环境变量读取，导出前还要检查压缩包成员与文本内容。外部服务不可用时，系统显示错误并回退，而不是让页面崩溃或制造结果。

### 7:10-7:40 后续计划

画面：

- 回到首页或系统状态页。
- 展示三个后续方向：OCR、真实评审网络外部接口复测、权限与学习证据增强。

口播：

> 下一阶段最值得做的是扫描版论文 OCR、在评审网络完成外部检索和模型调用的真实复测，以及增加学习证据与多用户权限隔离。我们的目标不是堆叠功能，而是让每个结论都有来源、每次测试都能复现。

## 录制后检查

- [ ] 成片时长在 5 至 8 分钟之间。
- [ ] 至少 2 分钟展示真实 AI 协同和修复过程。
- [ ] 所有页面来自实际运行，不是静态截图。
- [ ] 未出现 Key、邮箱、手机号、学号、绝对个人路径和隐私数据。
- [ ] 未公开再分发未授权论文全文。
- [ ] 视频中的测试数字与提交时真实输出一致。
- [ ] 音画同步，字幕无敏感信息，1080p 可读。
